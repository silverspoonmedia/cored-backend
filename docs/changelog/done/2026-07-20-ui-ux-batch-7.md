# UI/UX fixes batch 7

## Summary

Four targeted UI/UX fixes following user feedback after batch 6: card alignment on `users/edit`, file-hosting list-view symmetry + toolbar border, clickable breadcrumb parents on `activity-logs/{id}` (and two sibling trails), and a single delete button + cascade confirmation modal on `menus`.

## Outcomes

- **Breadcrumbs**: `routes/breadcrumbs.php` now passes `route()` URLs for `activity-logs.index`, `notifications.index`, and `profile.password.edit` parents. All parent crumbs are clickable; the renderer only links non-last items, so a missing URL previously rendered as dead text.
- **File-hosting list view**: empty row `colspan` corrected from `6` to `8` in `resources/views/adminlte4/file-hosting/index.blade.php` to span all columns (select, icon, name, type, size, region, visibility, actions).
- **File-hosting toolbar**: `.fh-toolbar` in `resources/css/file-hosting/file-hosting.css` now declares a full `border: 1px solid` + uniform `border-radius` (previously `border-bottom` only with half-rounded radius), so the search box reads as a symmetric shell.
- **Users edit alignment**: `resources/views/adminlte4/users/_activity_history.blade.php` drops `mt-3` so the "Recent activity" card aligns flush with "Edit user". Added an `@else` branch rendering `<x-adminlte4::empty-state>` when `$activityLogs` is empty, so the right column no longer collapses.
- **Menus action buttons**: `resources/views/adminlte4/menus/index.blade.php` replaced the twin inline delete buttons (regular + cascade) with a single delete trigger per row that opens a shared `#menuDeleteConfirmModal`. A cascade checkbox swaps the form `action` between the default and cascade URLs via JS (`data-menu-cascade-url`, `data-menu-confirm-template`). Fixes `btn-group` alignment broken by nested `<form>`.
- **Lang keys**: added `delete_confirm_title`, `delete_confirm_question`, `delete_cascade_option`, `delete_cascade_hint` under `lang/{en,id,ja}/web/menus.php`.
- **Tests**: extended `tests/Feature/Http/Controllers/Web/AccessibilityBladeTest.php` (8 new assertions) and `tests/Feature/Http/Controllers/Web/ThemeOverrideCssTest.php` (1 new assertion). All pass.
- **Docs**: `docs/web/ui-patterns.md` (breadcrumb policy, action buttons cascade pattern, card alignment, file-hosting toolbar) and `docs/web/blade-admin.md` (UX bullet list) updated.
