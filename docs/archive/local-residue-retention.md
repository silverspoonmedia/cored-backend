# Local residue retention

What this cleanup session deliberately kept out of the working tree, and why. Everything listed here is either gitignored, generated by a command you can re-run, or a live secret — none of it is source. The rule of thumb: a path stays only when a script, test, CI job or living doc reads it.

Verified 2026-11-22 while pruning the artifacts left by the localization waves, the domain sunset, the Microstock probe runs, the migration squash and years of `php artisan test`.

## Kept because the application reads it at runtime

| Path | Why it stays |
|---|---|
| `.env`, `.env.local`, `.env.profile` | Active local profile. `.env.profile` is read by `EnvSwitchCommandTest` (`tests/Feature/Console/EnvSwitchCommandTest.php`) and written by `env:switch`. Blanket-gitignored since the `.env.pre-archivd-backup` incident. |
| `.oci/production/`, `.oci/testing/` | **Live OCI KMS credentials** — each folder holds a `config` and a private `oci_api_key.pem`, selected by `APP_ENV` through `OciConfigPath` and `config/oci.php`. Deleting them breaks envelope encryption. Never tracked, never commit them. |
| `client-scaffold/` | Consumer template. `scripts/run-consumer-scaffold-check.php` copies it into a temp dir and boots it; the `scaffold` CI step runs that. Its own `vendor/` and `node_modules/` never exist here. |

## Kept because it is generated, gitignored, and re-runnable

| Path | Regenerate with |
|---|---|
| `backend-locale-report.json` | `php scripts/backend-locale-audit.php backend-locale-report.json`. Untracked during this session; `scripts/locale-report-query.php` exits 1 with that instruction when it is absent. |
| `storage/app/probe_results/` | `php scripts/microstock/probe_ai.php`, `probe_collection.php`, `probe_collection_stages.php`, the `billing_smoke_*` scripts, and `scripts/microstock/verify_e2e_asset.php`. The directory and its `.gitignore` stay; only uncited artifacts were removed. |
| `i18n-duplicate-report.json` (SPA) | `node scripts/i18n-duplicate-report.mjs`; read by `scripts/dup-query.mjs`. Cited by `docs/i18n.md`. |
| `.phpunit.result.cache`, `.phpstan.cache/`, `storage/logs/`, `storage/framework/{cache,views,sessions}/`, `bootstrap/cache/*.php` | `php artisan test`, `php artisan phpstan`, or any request. All were emptied here; nothing in them is evidence. |

## Removed, and where the evidence still lives

- The five `lang/` snapshot trees (`_audit_pre/`, `_snap_27d5eb3/`, `_snap_27d5eb3pre/`, `_snap_9ef90a3/`, `_snap_cfd57b6/`) were byte-identical to commits `27d5eb3`, `27d5eb3^`, `9ef90a3` and `cfd57b6`. Recover any file with `git show <sha>:lang/<path>`.
- `storage/app/migration-squash/` was the DDL-diff evidence of a finished squash; the live contract is [database-safety.md](../platform/database-safety.md#squashed-baseline) plus [migration-baseline.mdc](../../../.cursor/rules/migration-baseline.mdc), and the migrations themselves are the record.
- The Microstock probe JSONs and logs that no archive summary cites are gone; the summaries in [microstock-probes/](microstock-probes/) cite the 48 artifacts that remain, and those summaries are duplicated in the archive.
- Root scratch logs (`standalone-*.log`, `solo2/3.log`, `platform.log`, `notif.log`, `tmp-full2.log`), `.tmp-i18n/`, `.cursor/tmp/`, `storage/framework/views/`, the JUnit XML dump, the `_docs-diff.txt` and the ad-hoc `_audit*.php` probes were all output of finished sessions.

## Standing rule

Emptying these paths is always safe; *tracking* anything new under them is not. `php artisan test` holds an advisory lock on `bootstrap/cache/.phpunit.lock` so a second concurrent run cannot pollute them — see [reference-tooling.md — one suite at a time](../platform/reference-tooling.md#one-suite-at-a-time).
